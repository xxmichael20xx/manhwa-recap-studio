## 🌟 Overview

**Manhwa Recap Studio** is a professional desktop automation suite and narrative engineering framework designed to produce high-retention, logically sound webtoon and manhwa recap content.

Unlike low-tier channels that scrape unedited machine translations, this studio enforces **Zero-Slop** laws:
1. **Clean RPG Arithmetic:** Recalibrated $5,000\text{ EXP}$ progression thresholds; zero arbitrary stat bloat.
2. **Absolute Physical Durability:** Superhuman Constitution ($150–200+$) provides total physical invulnerability to mundane fodder ($Attack - Defence \le 0 \implies 0\text{ Dmg}$).
3. **High-Tactical Combat Realism:** Choke-point geometry and spatial awareness over single-file turn-based swarms.
4. **Calculated Antagonists:** Nobles and guild captains act with economic sanctions and political leverage rather than cartoonish screaming tantrums.
5. **Transformative Visuals & Uncapped Audio:** Built-in Midjourney/Fooocus Prompt Matrix generator with `--cref` character locking, coupled with built-in free Edge-TTS audio generation.

## 🚀 Quick Start (Running the Desktop Web App)

### 1. Install Dependencies
```bash
cd studio
npm install
```

### 2. Launch Studio Suite (Frontend + Backend)
```bash
npm start
```
* **Frontend Dashboard:** `http://localhost:3100`
* **Backend REST API:** `http://localhost:3101`
